Console input manual test

Open DevTools with F12 and pick the Console. Every message names its file and line on the right: inline ones come from this file (lines 23-41), the rest from js/console_input.js. Try typing doc, document.bo or demo (autocomplete), Shift+Enter for a new line, the Filter box (alpha, -tick, /l(o|i)g/) and the level buttons. Click a file:line link to open it in the Sources tab.
